# 不服來辯

跟毒舌的 Dylan 山羊老師吵架的網頁小遊戲。從他說出「不服來辯」開始，用選擇題回嘴，底氣歸零就輸，看你能撐幾回合。

- 選到神回會回血，選太弱或自爆會扣血，超時沒回答算沉默
- 三個階段：暖身、認真、地獄。越後面老師火力越強、作答時間越短
- 第 5 回合起會出現「假神回」：聽起來很嗆，其實會被老師反嘴
- 題庫 48 回合

## 排行榜

`index.html` 裡的 `FIRESTORE_PROJECT` 填上 Firebase 專案 ID，就是所有裝置共用的排行榜；留空則是每台裝置各自的排行榜。
Firestore 的安全規則在 `firestore.rules`。

角色和台詞都是虛構的。

直接打開 `index.html` 就能玩，不需要安裝任何東西。
